# 🤝 Projeto ONG

**Desenvolvimento Front-End para Web**

Projeto de website institucional para uma ONG fictícia que promove ações sociais, educação e apoio comunitário.

---

## 📖 Sobre o Projeto

Este é um projeto de desenvolvimento web front-end que visa criar um website completo e profissional para o **Projeto ONG**, uma organização fictícia dedicada a transformar vidas através de projetos sociais.

O site apresenta informações sobre a ONG, seus projetos, oportunidades de voluntariado e um formulário de cadastro para novos voluntários.

### 🎯 Objetivos

- Criar um website institucional completo e responsivo
- Aplicar boas práticas de desenvolvimento web (HTML5, CSS3, JavaScript)
- Implementar acessibilidade (WCAG 2.1)
- Desenvolver um projeto portfolio-ready

---

## 🚀 Tecnologias

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização e layouts responsivos
- **JavaScript** - Interatividade e validações
- **Git/GitHub** - Controle de versão
